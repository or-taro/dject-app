GPT 연결 관리

여러 개인 GPT가 같은 Dject 저장소를 사용할 수 있습니다. GPT별 이름과 용도는 이 브라우저에만 저장됩니다.

GPT에 Action 연결

  1. GPT 편집 화면에서 구성 → 작업 → 새 작업 만들기로 이동
  2. 인증을 API Key / Bearer로 설정하고 Dject Action 키를 입력
  3. 아래 OpenAPI 스키마를 붙여넣기
  4. 아래 GPT 지침을 GPT의 Instructions에 추가
내 GPT 열기 ↗
