Dject GitHub Pages 배포 체크리스트

1. GitHub에서 Dject 전용 저장소를 만든다.
2. 이 패키지의 site 폴더 안 파일들을 저장소 루트에 업로드한다.
3. GitHub 저장소 Settings > Pages에서 GitHub Pages를 켠다.
4. 생성된 Pages 주소를 연다.
5. 기존 "테스트 소설"이 목록에 보이는지 확인한다.
6. 아이디어/장르/분위기 등을 수정하고 "지금 저장"을 누른다.
7. ChatGPT의 디에게 같은 소설을 Dject에서 불러오라고 하여 동일 데이터인지 확인한다.

주의: 별도 로그인은 없다. 주소를 공유하지 않는 개인용 전제다.
